生成结构化产出，供用户搬运到 CC-PKM 端（Second Cortex 知识库）沉淀为原子卡片并更新项目状态。

执行步骤：
1. 回顾当前对话中已完成的工作（模块拆解、代码分析、开发成果等）
2. 按以下格式输出纯文本（用户将全选复制）：

```
## Debrief {YYYY-MM-DD}

### 模块拆解产出
（每个模块独立一段，格式如下。如本次无模块拆解则跳过此段）

#### {模块名称}
- **定位**：一句话说明该模块在 MetaBOC 系统中的角色
- **核心机制**：去时间化、去情绪化的客观技术描述（可直接作为原子卡片正文），尽可能详细
- **输入/输出**：数据流入口与出口
- **依赖关系**：上游模块 → 本模块 → 下游模块
- **关键代码路径**：核心文件与入口函数
- **论文映射建议**：该模块内容建议对应论文的哪个章节
- **建议 YAML 属性**：
  - asset_class: {architecture | methodology | canonical | constraint}
  - domain: {neuroscience | bioengineering | ...}
  - used_in: metaboc, thesis

### 开发成果
（如本次有二次开发工作则填写，否则跳过）
- 变更摘要：{做了什么}
- 影响范围：{影响了哪些模块}

### 状态变更（需 CC-PKM 端更新）
- Dashboard Active Focus：{哪些任务完成/新增/变更}
- 里程碑进度：{哪些子交付物有推进}

### 待沉淀任务
- [ ] {需要在 CC-PKM 端用 /card 执行的具体沉淀动作，每条对应一张卡片}

### 明日计划
- {下一步需要继续拆解/开发的方向}
```

3. 输出后提示用户：将此文本复制，回到 CC-PKM 端粘贴到 Daily Note 碎碎念区块，然后按"待沉淀任务"逐条执行 /card 沉淀。
